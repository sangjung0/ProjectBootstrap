## 개요

언어와 실행환경에 종속되지 않는 편집기·Git 설정과 README를 제공하는 템플릿입니다.

## 복사와 치환

이 템플릿의 숨김 파일을 포함한 내용을 대상 프로젝트에 복사합니다.
파일 내용의 다음 치환 키를 직접 바꿉니다.

| 치환 키                   | 지정할 값            |
| ------------------------- | -------------------- |
| `%%PROJECT_NAME%%`        | 프로젝트·저장소 이름 |
| `%%PROJECT_DESCRIPTION%%` | 프로젝트 설명        |
| `%%GITHUB_USERNAME%%`     | GitHub 사용자 이름   |

치환 후 `%%...%%`가 남아 있는지 확인합니다.

## 개발환경 구성

사용할 언어와 실행환경을 선택하고 필요한 소스, 의존성 설정, 실행 명령을 추가합니다.
